# Python Network Port Scanner

## 1. Introduction
This project is a simple Network Port Scanner developed using Python. It checks TCP ports on a target computer and identifies which ports are open.

## 2. Objective
- To understand how network ports work.
- To identify open TCP ports.
- To learn basic network security concepts.
- To practice Python socket programming.

## 3. Technologies Used
- Python
- Socket Library
- VS Code

## 4. Features
- Scans TCP ports from 1 to 100.
- Identifies open ports.
- Displays scan results in the terminal.
- Generates a scan report in a text file.

## 5. How to Run the Project

**Step 1:** Install Python.

**Step 2:** Open the project folder in VS Code.

**Step 3:** Open the terminal.

**Step 4:** Run this command:

```bash
python port_scanner.py
```

**Step 5:** Enter an IPv4 address when asked.

For practice, use:

```text
127.0.0.1
```

## 6. Output
The scanner displays open ports, if any, and creates a file named `scan_report.txt`.

## 7. Learning Outcomes
- Basic understanding of TCP ports.
- Knowledge of Python socket programming.
- Understanding of network scanning.
- Basic cybersecurity skills.

## 8. Safety Note
Use this tool only on your own computer or systems for which you have permission.
